# SGA-2025 AP03 CIGALE Preprocessing

Scripts live in this repository. Generated catalogs, smoke-test inputs, and reports
are written under `/Users/rfinn/research/SGA-CIGALE`.

## Current Selection Policy

- Preserve `/Users/rfinn/research/SGA2025/SGA2025-v1.0.fits` unchanged.
- Use `SGA2025.SGAID` as the object identifier.
- Use AP03 fluxes and AP03 flux uncertainties from `ELLIPSEPHOT`.
- Preserve the formal catalog uncertainties in the intermediate FITS table.
- Add a 0.1 mag systematic uncertainty in quadrature when writing CIGALE-facing
  flux errors. Sample-selection S/N values continue to use the formal errors.
- Convert nanomaggies to mJy with `1 nanomaggy = 0.003631 mJy`.
- Correct Milky Way extinction with `SGA2025.MW_TRANSMISSION_{band}`.
- Exclude `SAMPLE` bit `INSTAR = 16` from the first-pass CIGALE sample.
- Track `SAMPLE` bit `NEARSTAR = 8`, but retain those galaxies for now.
- Do not supply z-band photometry for `DEC >= 32.375` degrees.
- Do not impose S/N, missing-band, or other photometric-quality cuts.

## Filter Names

The CIGALE-facing table uses the CIGALE built-in GALEX/WISE filter names and
the short optical filter names from earlier Legacy Survey runs. The Legacy
Survey optical filters are exported from `speclite.filters`:

- `FUV`: `galex.FUV`
- `NUV`: `galex.NUV`
- `G`: `decamDR1-g` for `DEC < 32.375`; `BASS-g`
  for `DEC >= 32.375`
- `R`: `decamDR1-r` for `DEC < 32.375`; `BASS-r`
  for `DEC >= 32.375`
- `I`: `decamDR1-i` for `DEC < 32.375`
- `Z`: `decamDR1-z` for `DEC < 32.375`
- `W1`: `wise.W1`
- `W2`: `wise.W2`
- `W3`: `wise.W3`
- `W4`: `wise.W4`

`MzLS-z` is exported for reference, but it is not used by the current CIGALE
input because z-band photometry is not supplied for `DEC >= 32.375`.

## Commands

Export and import the Legacy Survey filters:

```bash
conda run -n cigale python /Users/rfinn/github/wisesize/scripts/export_speclite_legacy_filters_for_cigale.py \
  --add-to-cigale
```

Run the full preprocessing:

```bash
conda run -n cigale python /Users/rfinn/github/wisesize/scripts/preprocess_sga2025_ap03_for_cigale.py \
  --filter-map /Users/rfinn/github/wisesize/configs/sga2025_ap03_filter_map.json
```

Build the 20-row smoke-test input:

```bash
conda run -n cigale python /Users/rfinn/github/wisesize/scripts/make_cigale_test_sample.py
```

Run the current CIGALE smoke test:

```bash
cd /Users/rfinn/research/SGA-CIGALE/cigale_runs/smoke_test_speclite_legacy
XDG_CACHE_HOME=/Users/rfinn/research/SGA-CIGALE/cache \
MPLCONFIGDIR=/Users/rfinn/research/SGA-CIGALE/cache/matplotlib \
  conda run -n cigale pcigale check
XDG_CACHE_HOME=/Users/rfinn/research/SGA-CIGALE/cache \
MPLCONFIGDIR=/Users/rfinn/research/SGA-CIGALE/cache/matplotlib \
  conda run -n cigale pcigale run
```

The smoke run is intentionally only a mechanics test. It uses a tiny one-value
model setup generated by CIGALE so we can verify that the photometry table,
filter names, redshift column, and output writing all work. The 20-row smoke
sample is balanced across `DEC = 32.375` so both DECam DR1 and BASS filters are
exercised.
